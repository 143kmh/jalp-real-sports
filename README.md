# Real Manager — 0.4.6

Локальный инструмент для Windows 10/11 x64: отдельный профиль установленного Chrome, работа в отдельном окне, General / Player packs, защита карт и диагностика. Сервер доступен только на 127.0.0.1:5127. Это независимый проект, не официальный клиент Real.

## Запуск двойным кликом

1. Скачайте `RealManager-0.4.6-win-x64.zip` в [Releases](https://github.com/143kmh/jalp-real-sports/releases).
2. Распакуйте **весь архив** в свою доступную для записи папку, например `Documents\RealManager`. Не запускайте .exe прямо внутри ZIP.
3. Дважды нажмите `Real Manager.exe`. Панель откроется отдельным окном Chrome, без терминала. Node.js включён в portable-сборку; отдельно устанавливать его не нужно. Google Chrome должен быть установлен.
4. Для быстрого доступа создайте обычный ярлык этого .exe на рабочем столе.

Повторный запуск использует уже работающий сервер из этой же папки. Закрытие панели не останавливает задачи; завершение — кнопкой «Завершить приложение» в разделе «Приложение». Окно панели имеет отдельный профиль `data/panel-profile`, не смешанный с браузером Real. Лаунчер не требует прав администратора и не меняет системные настройки. .exe не подписан сертификатом; Windows может показать предупреждение издателя.

Не запускайте две копии приложения на одном порту. Для обновления завершите приложение и замените файлы в прежней папке, **сохранив `data/`**. Сборка не содержит аккаунтов: новая папка начинает с пустого списка.

## Из исходников

Требуются Node.js 22.12+, Google Chrome и для сборки лаунчера — стандартный компилятор .NET Framework 4.x на Windows. Откройте PowerShell в папке проекта:

```powershell
npm ci
npm test
npm run build:windows
.\'Real Manager.exe'
```

`npm run build:portable` собирает ZIP в `releases/`: скачивает закреплённый официальный Node.js v24.19.0, проверяет SHA-256 из SHASUMS256.txt, включает LICENSE среды и устанавливает зависимости по lockfile без install-скриптов. При ограничении PowerShell можно запустить `node server.mjs` и вручную открыть `http://127.0.0.1:5127/`.

Для неинтерактивной проверки запуска: `.\'Real Manager.exe' --no-ui`. Альтернативный локальный порт задаётся переменной `REAL_MANAGER_PORT`; это не настройка доступа из сети.

## Добавление аккаунтов — без HAR

1. Один раз установите расширение в служебном Chrome, как описано в разделе «Окно Real и диагностика». В панели откройте «Аккаунты» → «Добавить аккаунты».
2. В отдельном обычном Chrome вручную войдите в один аккаунт Real. Вход не автоматизируется; проверки сайта не обходятся.
3. Окно Chrome не закрывайте. В панели нажмите «Готово · открыть Real», когда появилось имя подтверждённого аккаунта.
4. Дождитесь имени подтверждённого аккаунта. Приложение проверяет профиль через GET /user и сохраняет сессию с Windows DPAPI. Если Real использовал кэш профиля, приложение проверяет сессию из успешного запроса этого браузера. Пароли, cookies и challenge-токены не импортируются.
5. Для следующего аккаунта повторите шаги. Старые записи / правила остаются, но аккаунт без нового входа не включается в задания.

Ваши вкладки Real в Helium держать открытыми не нужно. Не передавайте data/browser-profile, accounts.dpapi или весь каталог data другим людям.

Публичный репозиторий и portable ZIP содержат только код, зависимости и среду исполнения. Файлы HAR, сессии, настройки ваших аккаунтов, история операций, профили Chrome, скриншоты и диагностика не включаются. `helium-extension` содержит общие адаптеры DOM; новая устанавливаемая папка — `chrome-extension`. Рабочие адаптеры копируются туда при запуске приложения.

## General packs

1. Выберите аккаунты и лиги. Стрелки меняют приоритет; «Добавить лиги» раскрывает остальные лиги.
2. Настройте автолистинг: Default / Min / Max, всегда 24 часа. Защищённые игроки / ID карт, Untouchable, бустеры и непродаваемые карты остаются.
3. Сохраните правила, если меняли настройки.
4. Нажмите «Открыть максимум · выбранные» или «На всех аккаунтах» и подтвердите расход всего доступного игрового баланса, включая поступления во время работы.

General всегда открывается до недоступности, без ограничения количества. Каждый аккаунт заканчивается перед следующим. В начале — обновление Real; если аккаунт переключён, обновление повторяется после переключения. Перед покупкой проверяются аккаунт, тип пака, лига, цена и баланс.

Лига заканчивается при подтверждённом ограничении Real либо нехватке текущего баланса. Перед следующим аккаунтом выполняется свежая проверка всех выбранных лиг. Если снова доступна более приоритетная лига, бот возвращается к ней.

Потерянная сводка / временная ошибка → пауза 2–120 секунд, обновление страницы, новое открытие на том же аккаунте. Старый запрос покупки или листинга не отправляется повторно. Неизвестные попытки учитываются отдельно. Карты неизвестного открытия и карты после ошибки Quick list могут остаться без листинга; через историю бот их не выставляет.

Таблица «Прогресс открытия» показывает лиги, подтверждённые открытия, неизвестные попытки и восстановление. Зелёный аккаунт означает завершённую проверку всех лиг, а не гарантированную успешность каждого листинга. Подробности — в журнале «Приложение». Старые задания без подробных данных по лигам не помечаются зелёными задним числом.

401/403, вход / ручная проверка Real и ошибка записи на диск останавливают очередь. Число повторов временных ошибок не ограничено. «Остановить очередь» запрещает следующие покупки, но не отменяет уже отправленную. После перезапуска приложения незавершённая задача не возобновляется автоматически.

## Окно Real и диагностика

Real работает в отдельном обычном Chrome с собственным профилем и расширением Real Manager. Puppeteer / CDP для рабочего браузера не используются. При первом запуске вручную загрузите папку `chrome-extension` через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное». Затем обновите Real и вкладку локальной панели, открывшуюся в этом же Chrome. Вкладка подключения закроется после успешного соединения. При следующих запусках подключение автоматическое. Панель приложения можно закрыть, но окно Real и ПК должны оставаться открытыми / включёнными. Во время задачи не кликайте в Real; ручная проверка сайта не обходится.

«Скачать диагностику» создаёт локальный ZIP: снимок структуры / текста интерфейса, маршруты и статусы API, ошибки. В новом режиме изображения экрана пока не включаются. Заголовки, тела запросов, cookies, проверочные токены и значения полей не экспортируются. ZIP содержит имена / ID аккаунтов и сведения о картах — проверьте перед передачей. Автоматической отправки нет.

## Scenario Recorder

В разделе «Приложение» можно записать отдельный ручной сценарий Real, например применение бустера. Укажите название, нажмите «Начать запись», выполните только нужную последовательность действий в служебном Chrome и нажмите «Завершить и скачать ZIP».

ZIP содержит `scenario.json`: видимые состояния интерфейса вокруг ручных кликов / изменений и сетевые метаданные `METHOD + PATH + STATUS` за время записи. Значения полей, тела запросов / ответов, cookies, authorization/session headers и challenge-токены не сохраняются. Видимый текст страницы может содержать имена аккаунтов, игроков и карт — файл нужно просмотреть перед передачей.

Во время записи автоматические задачи и управление служебным браузером блокируются. Recorder предназначен для изучения нужного пользователю workflow, а не для фоновой записи всего браузера.

## Boosters

В разделе «Бустеры» выберите аккаунт и загрузите owned игроков. Для конкретного игрока можно включить автоматический буст и задать максимальную желаемую редкость: Rare, Epic или Legendary. Если выбранная редкость недоступна, используется fallback вниз: Legendary → Epic → Rare либо Epic → Rare.

«Забустить всех играющих сегодня» не требует отдельного списка игроков: бот читает Today’s players для доступных видов спорта и берёт owned-карты текущего аккаунта. «Не применять Legendary» глобально запрещает Legendary даже для игроков, у которых она выбрана индивидуально. Один запуск обрабатывает первые 25 подходящих игроков и применяет не более одного бустера к каждому.

Внутри редкости бот предпочитает характеристики, подходящие позиции игрока (например QB — PYDS/PTD, RB — RUYDS, баскетбольный guard — PTS/AST/3PM, футбольный forward — GOAL/AST). Если подходящего варианта нет, используется любой доступный бустер выбранной редкости. Само применение выполняется штатным интерфейсом Real и отдельно авторизуется непосредственно перед кликом. Потерянный ответ после отправки не повторяется автоматически; 401/403 и ручная проверка Real останавливают очередь.

## Остальной функционал и проверки

Player packs: выбор аккаунта, спорта, игроков и количества; покупка только за 200 Rax; все карты сохраняются. Полное восстановление Player после неизвестного результата ещё не доделано. Main-аккаунт пока не реализован.

```powershell
npm test
```

Тесты используют искусственные ответы / DOM и не покупают паки. General проверен тестами и просмотром локальной панели; полный сценарий покупки / лимита / Quick list в служебном браузере требует проверки пользователем на реальном запуске.
